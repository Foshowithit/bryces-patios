# Bryce's Patios — SEO ops README

Everything under `SEO/` is the visibility stack for [brycespatios.work](https://brycespatios.work).
This file is the operator's map: what each file is, how to rebuild, how to ping, and the
rules that keep the site honest and out of trouble.

---

## 1. Build the site

The site is **static HTML generated by a Python emitter**. Never hand-edit generated pages —
they get overwritten.

```bash
cd "/Users/adam26/WorkBuddy AI/2026-09-23-22-57-30/bryces-patios"
python3 work/gen/emit.py
# → wrote 81 pages, sitemap has 81 urls, feed has 14 entries
```

- `work/gen/site.py` — **data module** (no `__main__`). Business constants, `GUIDES`,
  `SERVICES`, `TOWN_INTRO`, and the shared HTML shell (`head()`, `NAV`, `footer()`,
  `render_shell()`, `RELATED`, `GUIDE_SERVICE`). Edit copy and layout here.
- `work/gen/emit.py` — **the build**. `main()` writes every page + `sitemap.xml` + `feed.xml`.
- `index.html` — **hand-maintained home page**, NOT emitted. After any `V` (cache-buster)
  change you must update it by hand: `assets/css/style.css?v=<V>` and `assets/js/main.js?v=<V>`.
- 80 emitted pages + 1 hand-maintained home = 81 sitemap URLs (home is counted in the sitemap).

Expected output after a clean run: `wrote 81 pages, sitemap has 81 urls, feed has 14 entries`
(13 feed entries = the `/learn/` hub + 12 guides).

## 3. Discovery plumbing

### `feed.xml` (Atom)
Built by `build_feed()` in `emit.py`. Covers `/learn/` plus all 12 guides, newest-first by
file mtime. Every page carries
`<link rel="alternate" type="application/atom+xml" href="https://brycespatios.work/feed.xml">`
in `<head>` (added inside `head()` in `site.py`) and a "Guides feed" link in the footer.

### `sitemap.xml`
Built by `build_sitemap()` in `emit.py`: 81 URLs, real `lastmod` per file, plus the Google
image-sitemap extension (`image:image`) for hero images.

### IndexNow (Bing / Yandex / Seznam / Naver)
- Key file: `<32-hex>.txt` at repo root (also mirrored in `work/.indexnow-key`).
- Ping script: `work/indexnow-ping.sh` — POSTs every sitemap URL to
  `https://api.indexnow.org/indexnow`.

```bash
bash work/indexnow-ping.sh
```

> **Honest limitation:** **Google does not participate in IndexNow.** This only nudges Bing,
> Yandex, Seznam and Naver. Google discovery depends on the sitemap + Search Console.

## 4. Monitoring

`~/tmp/bryce-seo-watch/watch.py` runs weekly via crontab (`0 9 * * 1`). It fetches the live
site, checks every sitemap URL and the learn hub card count, and reports
`urls=81 ok=81 bad=0 hub_cards=13`.

> `automation_update` is not callable in this environment — **crontab is the route** for
> scheduling. Do not try to create the watcher as an app automation.

## 5. Google probe rules

Probing Google for rank checks burns an IP lease fast:

- **≤ 3 queries per session.**
- 10–20 s spacing between queries.
- ≤ 1 probe session per hour.
- Google's wall sits at ~3 queries → IP `100.40.45.60`.

Bing / DuckDuckGo / Startpage / Mojeek / curl are all blocked on this machine. Use a real
browser (ego-browser), or the `web-research` skill as fallback.

## 6. Schema / entity rules (do not violate)

- One business `@id` scheme everywhere: `https://brycespatios.work/#business`.
- Remove `foundingDate` (unverified) — no invented dates.
- Weekend hours in schema must match page copy: **Mon–Fri 8–6, Sat/Sun by appointment**.
- `sameAs` = the single Facebook page. **Never edit Bryce's Facebook page.**
- **No `aggregateRating`** until ≥5 real reviews exist.
- **Never invent** licenses, insurance, warranties, years in business, crew size or reviews.
- `sameAs` / `areaServed` / `geo` are the only place towns are asserted as structured data.
- Coordinates `42.022753;-71.256955` are verified — **do not re-geocode**.
